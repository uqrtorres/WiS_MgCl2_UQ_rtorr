Examples of code used to analyse the bulk WiS electrolyte environments

TIP5P_Cluster_Analysis.py:
Identifies all the clustering behaviours (Mg-O and Mg-Cl coordination, average and total coordination numbers and cluster types) in a given bulk WiS electrolyte

TIP5P_Cluster_Comparison.py:
Identifies which Mg clusters have changed over the equilibration process. Provides the indices for both clusters that have changed and clusters that have not changed.

TIP5P_Cluster_Monitoring.py:
Tracks the Mg-O and Mg-Cl coordinations for a given Mg index over the equilibration process
