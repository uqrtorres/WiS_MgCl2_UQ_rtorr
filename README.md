Repository that contains example python codes used throughout the honours project


bulk_analysis: Code that analysed the clusters in the pure bulk WiS systems


free_water: Code that analysed the free water in a WiS system


pris_g: Code that analysed the clusters in the pristine graphene (pris-g) WiS systems


2.5V_Density_Profile.py: The code used to plot the linear density profiles for pris-g systems
